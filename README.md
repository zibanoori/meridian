# Meridian | E-Commerce Template

A modern, responsive, and accessible e-commerce template built with HTML5, CSS3, and Bootstrap 5.

## 🚀 Features
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop devices.
- **Dark/Light Mode:** Seamless theme switching with local storage support.
- **Accessibility:** Built with ARIA attributes and semantic HTML for better inclusivity.
- **Modern UI:** Clean aesthetics with smooth animations and hover effects.

## 🛠️ Technologies Used
- HTML5 & CSS3 (Custom Properties, Flexbox, Grid)
- Bootstrap 5.3
- JavaScript (ES6+)
- Font Awesome & Bootstrap Icons

## 📂 Project Structure
- `assets/css/`: Contains all styling files including `style.css`, `sections.css`, and `responsive.css`.
- `assets/js/`: Includes core logic in `main.js` and specific features like `home.js`.
- `index.html`: The main landing page of the application.
